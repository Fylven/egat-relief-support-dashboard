# EGAT Support Dashboard

Dashboard สำหรับติดตามและสรุปข้อมูลการสนับสนุนถุงยังชีพและน้ำดื่ม
แก่ผู้ประสบอุทกภัยในพื้นที่ อปก. ปี 2569

## 📌 รายละเอียด

เว็บไซต์สำหรับแสดงภาพรวมการดำเนินงานด้านการสนับสนุน
โดยสามารถดูข้อมูลตามพื้นที่ วันที่ และสถานะการสนับสนุนได้

## ✨ ฟังก์ชันหลัก

- 📊 แสดงภาพรวมการสนับสนุน
- 🗺️ แสดงพื้นที่ดำเนินการ 14 จังหวัด
- 📅 ค้นหาข้อมูลตามช่วงวันที่
- 📍 กรองข้อมูลตามจังหวัด
- ✅ แสดงรายการที่สนับสนุนแล้ว
- ⏳ แสดงรายการที่ยังไม่ได้สนับสนุน
- 📋 สรุปข้อมูลรายจังหวัด
